# POPC 63 + 63 custom patch candidate

`POPC-OpenMM86-63x63.pdb` is a **candidate input** for OpenMM 8.6.0
`Modeller.addMembrane(lipidType=PDBFile(...))`. It is not an applicable
construction or optional-equilibration policy. [OpenMM's `addMembrane`
reference](https://docs.openmm.org/latest/api-python/generated/openmm.app.modeller.Modeller.html#openmm.app.modeller.Modeller.addMembrane)
supports a custom `PDBFile`, `PDBxFile`, or another object with `topology` and
`positions`, and describes its intended input as a pre-equilibrated solvated
patch. This derivative has two lipid vacancies and therefore needs separate
physical validation before that description can be claimed for it.

## Source and exact derivation

- Source: `openmm/app/data/POPC.pdb` installed with OpenMM 8.6.0,
  `8.6.0.dev-c6173db`, SHA-256
  `a35daa948562a67c142ea5ba38c1e18cc7a50bc1afc559338b2565d23fd38a29`.
  The [OpenMM 8.6 source](https://github.com/openmm/openmm/tree/8.6.0/wrappers/python/openmm/app/data)
  and current upstream patch have the same bytes as this installed resource.
- Exact observed source defect: POP residue `109`, in the lower leaflet, has
  the opposite glycerol `O21,C1,C3,HS` handedness from the pinned
  `Lipid21:POPC:sn-2R` representation. The other 127 source molecules pass the
  representation's molecular graph, glycerol and cis-alkene checks.
- Deterministic paired deletion: remove residue `109` and upper-leaflet
  residue `62`. Residue `62` is the unique upper phosphate closest in periodic
  XY to residue `109`'s phosphate, at `2.225242 Å`. The paired deletion
  preserves equal source populations while creating nearby vacancies on both
  sides. All surviving atoms retain their original coordinates and bonds.
- Derived file SHA-256:
  `92a19c3470605d44ca779772f306ad693afdd11f1f78176655a3f1d2ee3a77b4`.
  The resulting cell remains `63.701 × 66.874 × 73.136 Å`, with 63 POP
  molecules per leaflet and 5,120 waters. It has 32,244 atoms and 26,998
  bonds. The geometric XY area divided by molecules per leaflet changes from
  `66.562` to `67.618 Å²`; that quotient does not establish an equilibrated
  area per lipid.

Run `out/python/bin/python scripts/generate-popc-candidate-patch.py --check`
from the repository root to reproduce and verify the asset without writing.
Use `--write` to regenerate it from the pinned installed source. The generator
checks the source and derived hashes; source molecule identities, exact
graph and stereochemistry; the unique nearest opposite-leaflet deletion;
survivor order, atom identities, coordinates and bonds after PDB readback;
the unchanged cell; and all 126 surviving molecules' sn-2 and cis chemistry,
phosphate sides and head-to-tail orientations. A different OpenMM build,
source patch, catalogue representation, or generated byte sequence is refused.

## Remaining evidence

The paired deletion leaves vacancies in a patch that OpenMM otherwise treated
as pre-equilibrated. Before this candidate can support a positive source
class, verify its parameterization, periodic packing, area/thickness and
head/tail organization; exercise the actual protein-specific provider return
and downstream minimization; and establish matched POPC scientific controls
for the proposed optional-equilibration pressure treatment. A chemically
correct, exactly reproduced asset alone establishes none of those outcomes.
